# 需求规格说明（模拟）：知识问答 → 文档修订 → 可检索 → 原型生成

> **文档性质**：虚构业务场景，用于演示与联调流程，非真实客户约束。  
> **版本**：v0.1（模拟）  
> **日期**：2025-03-21

---

## 1. 项目概述

### 1.1 背景

「智研工作台」面向产品与设计团队，在统一知识库中沉淀需求、交互说明与接口约定。用户通过**问答（QA）**快速查资料；当知识缺失时，通过**意见反馈**触发**文档修订**；修订并重新索引后，同类问题可被检索；检索到的依据将输入**原型生成**模块，输出可预览的界面原型与说明。

### 1.2 目标

- 首次提问时若检索无命中或置信不足，系统给出**可理解的空结果说明**与**下一步引导**（补充文档 / 提交修订意见）。
- 修订闭环完成后，**同一语义的问题**能在合理延迟内被检索到。
- 原型生成**显式依赖**检索片段，降低无依据编造。

### 1.3 范围（本模拟文档内）

| 在范围内 | 不在范围内（本模拟） |
|----------|----------------------|
| QA 检索、空结果体验 | 多租户计费 |
| 意见驱动修订、版本留痕 | 移动端离线 |
| 重索引与检索一致性 | 第三方 SSO 深度集成 |
| 原型生成与引用展示 | 代码级组件库导出 |

## 4. 用户场景与验收标准

### 场景 A：首次提问检索不到

**描述**：成员在 QA 输入与当前知识库表述不一致或知识尚未覆盖的问题。

**期望行为**：

1. 返回状态明确区分：**无命中** / **低置信命中**（阈值可配置）。
2. 展示简短原因说明（例如：知识库中暂无相关段落）。
3. 提供操作入口：**去补充文档**、**提交修订意见**（可带当前问题预填）。

**验收**：在无向量命中的请求下，不出现伪造具体业务条款的「完整答案」；日志可追踪 `document_id` 与检索分数。

---

### 场景 B：意见驱动修订

**描述**：成员针对「答不上来」或「答不全」提交结构化意见（缺失要点、错误假设、希望补充的章节等）。

**期望行为**：

1. 意见与 **QA 会话 ID**、**用户原问题** 可选关联。
2. 生成修订任务；修订完成后文档版本 +1，保留变更摘要。
3. 修订完成后自动或手动触发**该文档（或全局）重嵌入/重索引**。

**验收**：修订任务状态可查询；同一文档历史版本可对比（至少展示摘要）。

---

### 场景 C：修订后可检索

**描述**：修订并索引完成后，用户再次提出**语义等价**的问题。

**期望行为**：

1. 检索能返回与修订内容对应的切片，且排序合理（向量 + 可选精排）。
2. 答案正文需带**引用片段或文档定位**（标题/段落/ chunk 索引）。

**验收**：在测试集「修订前 0 命中、修订后 ≥1 相关命中」用例上通过。

---

### 场景 D：检索结果用于原型生成

**描述**：成员在原型模块输入高层需求，系统结合**最新可检索知识**生成界面草案。

**期望行为**：

1. 原型生成前可选择「是否强制先检索」；强制模式下无足够引用时阻断或降级提示。
2. 输出侧展示**引用来源列表**（文档名 + 片段摘要）。
3. 支持从 QA 会话一键「带入问题与检索上下文」到原型会话（模拟能力）。

**验收**：原型说明页可展开查看引用；无引用时不声称「来自内部文档第 X 条」。

## 5. 功能需求（编号）

| ID | 需求描述 | 优先级（模拟） |
|----|----------|----------------|
| FR-01 | QA 支持空结果/低置信分支与统一错误码 | P0 |
